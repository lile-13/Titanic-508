## 运行方法

在仓库根目录运行，环境为 Python 3.14（`requirements.txt` 已新增 `lightgbm==4.7.0`）：

```powershell
# 直接运行源码
python notebooks/source/05_对照模型与误差分析.py

# 或：重新生成并执行 Notebook（修改源码后必须这样做，不能保留旧输出）
python -m scripts.py2nb "notebooks/source/05_对照模型与误差分析.py" --outdir notebooks
python -m scripts.run_notebook "notebooks/05_对照模型与误差分析.ipynb"
```

## 关键约定（与全组一致）

- **统一折划分**：使用 `features/folds.csv`（按 GroupId 的 StratifiedGroupKFold，5 折，seed=42），按 PassengerId 关联，不自行重新切分。
- **逐折独立填补**：每折通过 `src.preprocess.prepare_fold_matrices(strategy="rule_group")` 从原始特征构建矩阵，填补器只拟合训练折；不在 `features/train_clean.csv` 上直接切折。
- **指标**：Accuracy（比赛口径）+ AUC + LogLoss。
- **可复现**：全部模型固定 `random_state=42`。

## 结果（2026-10-18，Python 3.14.7；建模矩阵 59 列，已含成员3新增的 CabinZone 特征）

### 模型对比（5 折 CV，均值 ± 标准差）

| 模型 | Accuracy | AUC | LogLoss |
|---|---|---|---|
| **LightGBM** | **0.8108 ± 0.0117** | **0.9039** | **0.3825** |
| 逻辑回归（基线） | 0.7954 ± 0.0057 | 0.8854 | 0.4239 |
| 随机森林 | 0.7874 ± 0.0076 | 0.8790 | 0.4393 |

每折 Accuracy（LGB / LR / RF）：0.8039/0.7982/0.7803，0.8304/0.8039/0.7999，0.8131/0.7936/0.7867，0.8032/0.7900/0.7825，0.8032/0.7911/0.7877。

**LightGBM 在每折上都最高，比 RF 高约 2.3pp、比 LR 高约 1.5pp，是三个对照模型里的最优单模型。**

### 误差分析（RF vs LGB）

| 情况 | 样本数 |
|---|---|
| 两模型都对 | 6500 |
| 两模型都错 | 1300（15.0%） |
| 仅 RF 错 | 548 |
| 仅 LGB 错 | 345 |

- 两模型**共同错误占多数**，说明这部分样本主要是特征信息不足，不是模型差异导致；
- **仅 LGB 错（345）明显少于仅 RF 错（548）**，与 LGB 整体准确率更高一致；
- 分组错误率与混淆矩阵见 `member4_group_error_rate.csv` / `member4_group_error_rate.png` / `member4_confusion_matrix.png`。

### 融合实验（概率平均 soft voting）

| 折 | RF | LGB | Fusion(0.5) | 折内最优权重 w | 融合是否不差于最优单模型 |
|---|---|---|---|---|---|
| 1 | 0.7803 | 0.8039 | 0.8068 | 0.4 | 是 |
| 2 | 0.7999 | 0.8304 | 0.8217 | 0.0 | 否 |
| 3 | 0.7867 | 0.8131 | 0.8085 | 0.0 | 否 |
| 4 | 0.7825 | 0.8032 | 0.8084 | 0.4 | 是 |
| 5 | 0.7877 | 0.8032 | 0.8032 | 0.1 | 是 |

- 简单平均融合(0.5)均值 **0.8097**，仍**低于** LGB 单模型 0.8108，且仅在 3/5 折不差于最优单模型 → **融合不构成稳定优于单模型**（"稳定"要求 5/5 折都不差）；
- 拼接全部验证集后全局最优权重 w=0.1（几乎全押 LGB），Accuracy 0.8130，比 LGB 仅高约 0.22pp；该权重在验证集上挑选，存在轻微过拟合风险，且提升幅度不构成稳定结论。

## 最终建议

1. **以 LightGBM 为对照组最优单模型**（0.8108 ± 0.0117），可与成员1的 CatBoost 主力模型直接比较（同折同指标）。
2. **不建议采用概率平均融合**：RF 明显弱于 LGB，简单平均反而拖低分数；若后续要融合，应只融合与 LGB 水平相近的模型。
3. **建议提交**：`reports/experiments/member4_suggested_submission.csv` 由 LGB 在全部训练数据上重训后预测生成（命名"建议"，不覆盖成员1的最终提交职责），可直接与成员1的方案做集成或替换验证。
