## 课程源码包

`scripts/package_final_delivery.py`打包源码、公开原始数据、折映射、实验记录、最佳组合模型及作者检查点，并保留TabICL的BSD许可。虚拟环境和Git目录不进入压缩包；报告DOCX单独交付。运行时指定输出目录和课程文件名：

```powershell
python -B -m scripts.package_final_delivery --destination outputs/course_delivery --archive-name final-course-source
```
