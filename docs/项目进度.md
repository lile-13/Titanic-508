# 项目概览

本项目使用 Spaceship Titanic 乘客属性、舱位与消费记录预测是否被传送。最终方案为树模型集成 25% 与 TabICLv2 75% 的概率融合，分类阈值为 0.5。13次已完成的平台提交中，最高公开评分为 **0.81318（81.318%）**。
