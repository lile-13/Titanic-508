# TabICL失稳诊断与概率平均（2026-10-30）

本轮得到一个通过固定验证门槛、尚未提交Kaggle的候选。原45模型集成继续作为平台最佳方案，已观测成绩仍是0.81108。课程报告和源码ZIP保持暂停。

## 找到了什么

先检查此前TabICL最差的历史划分：第二次重复验证的第3折。验证集1751人，其中G甲板502人、冷冻G甲板264人。此前“原树模型与默认TabICL各50%”的融合，相对原树模型整体净少对32人，G甲板少对39人；冷冻G乘客的假阴性从13人增加到103人。

固定这1751人的验证集，只改变TabICL训练上下文中的完整同行组。使用一半训练组、三个固定种子时，G甲板净变化分别为+10、-7、-38人；使用75%训练组为+1、-1、-36人，全量为-39人。这说明预测对训练上下文构成敏感，不能得出“数据越少越好”的结论。样本子集重叠，且故意检查了已知坏折，只用于诊断，不用于选采样比例。

进一步导出同一个模型的8个内部视图。在坏折的冷冻G乘客中，各视图平均正类概率为0.4614、0.5217、**0.001185**、0.6510、0.4643、0.6003、0.6685、0.6890。第3个视图把这264人全部判为False。默认聚合先平均logit再转概率，极端置信度会放大这个视图的影响：聚合后的平均概率降到0.3730；同样8个视图改成算术概率平均则为0.5072。

这解释了该折概率坍塌的一部分机制，尚未解释单个视图为什么失效。概率平均也没有完全解决G甲板问题：该历史折整体净变化从-32缩小至-5人，G甲板从-39至-12人，冷冻G从-27至-4人。不能把它写成“G甲板问题已修复”。
