## 给建模成员的必读说明

### 人数计数必须统一口径

姓氏跨 train/test：1536 个姓氏两边都有。分别计数时 SurnameSize 均值是 5.326 和 3.505；合并计数后是 7.085 和 7.079。
因此统一使用 `build_features_combined(train_raw, test_raw)`。

这只使用公开的无标签特征，不读取测试标签，但确实使用待预测批次的特征分布。
本项目 CV 与最终训练都采用同一批次计数设定；不能将此描述成“完全不使用测试特征”或直接外推到任意未来单行预测。
旧版对抗 AUC 0.7336 → 0.5454 是缺失标记被丢弃时的历史结果；本次结果以 Notebook 04 和 reports/experiments/adversarial_comparison.csv 为准。
对抗 AUC 接近 0.5 只是未发现明显可区分信号，不证明分布完全相同，也不保证本地分数与榜单一致。

### CV 必须每折独立拟合填补器

**不要直接在 train_clean.csv 上切五折来报告正式验证分数。** 该文件使用了全部训练行的填补统计量，适合方案确定后的全量训练。
下面从原始数据构建未填补的特征，再按照统一的 fold 映射处理。按 PassengerId 关联，不依赖 CSV 行号。

```python
import numpy as np

from src import preprocess as pp

features, test_features = pp.build_features_combined(train_raw, test_raw)

assert fold_map.PassengerId.is_unique
fold_of = features.PassengerId.map(fold_map.set_index("PassengerId")["fold"])
assert fold_of.notna().all() and fold_of.isin(range(1, 6)).all()

for fold in range(1, 6):
    tr_idx = np.flatnonzero((fold_of != fold).to_numpy())
    va_idx = np.flatnonzero((fold_of == fold).to_numpy())
    Xtr, ytr, Xva, yva = pp.prepare_fold_matrices(
        features, tr_idx, va_idx, strategy="rule_group")
```

`prepare_fold_matrices` 返回 Xtr、ytr、Xva、yva，并对齐类别编码列。
strategy 可为 simple、indicator、rule_group；None 为保留缺失的基准。drop 只用于完整样本子集分析，不能用它生成最终测试预测。
若使用 CatBoost 原生类别输入，可自行在相同训练折上 fit Preprocessor 并分别 transform；不能提前全量填补。

## 清洗逻辑和结论边界

- train 8693 行、test 4277 行；不删除默认输出中的乘客，不改已知标签。
- HomePlanet、Cabin.Side 在观测到的组内恒定：仅在同组已知值唯一时用来补缺。
- Destination 在 717 个组、Deck 在 421 个组内存在不同取值：现在统一回退到训练折众数，不再直接复制同组首值。
- 同姓氏不等于同组：2217 个姓氏中 1664 个跨组。
- Age、消费、VIP、CryoSleep 的组内统计填补保留为启发式候选，不宣称它们是组内恒定属性。
- 数据中观测到冷冻者已知消费均为零；正消费可以用来补部分缺失 CryoSleep。规则收益以本次消融结果为准。
- 年龄 0 保留；消费先补缺，再重算总额、零消费标记、log 和消费结构，避免派生列与清洗值不一致。
- 列间缺失相关最高约 0.025，仅提示共同缺失结构较弱，不证明完全随机缺失。
- **撤回旧“S3 零收益”结论。** 旧代码生成缺失标记后被矩阵白名单丢弃，S2/S3 实际使用相同输入。修正后标记真正入模，每折有断言；效果见重跑结果。
- LogTotalSpend 可供模型比较；单变量线性相关更强不能推出所有模型都必须取 log。
- S1 删除约 24% 样本，验证对象也缩小，不能与覆盖全体验证行的方案直接排名。
- 小幅均值差异不能仅凭五折结果宣称显著提升；同一模型和固定折下比较，再判断是否值得增加复杂度。
