# 课程实验报告

[下载完整报告 Word 文件](大作业综合报告.docx)

报告介绍 Spaceship Titanic 预测任务、小组分工、数据清洗与特征工程、模型训练与融合，以及 Kaggle 提交结果。最终方案为树模型集成 25% 与 TabICLv2 75% 的概率融合，已观测的最高公开评分为 **0.81318（81.318%）**。

项目全部源码和实验记录见[仓库主页](https://github.com/lile-13/Titanic-508)。环境安装、固定方案重建及预测命令见[项目说明](../../README.md)；比赛原始数据和大型模型权重不包含在 Git 仓库中，获取及重建方式已在项目说明中列出。
