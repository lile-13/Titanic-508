# 成员1：训练与预测第一版

日期：2026-10-18。本阶段目标是跑通独立的训练、五折验证、折外预测、模型保存和提交文件生成。
逻辑回归与CatBoost均从原始数据出发，沿用成员2/3的特征和统一折划分。

## 代码从哪里看起

| 文件 | 作用 |
|---|---|
| src/train.py | 核心训练流程、输入准备、折映射校验、模型工厂、预测和提交格式校验 |
| scripts/train.py | 训练命令行参数；默认只跑五折，--fit-full额外全量训练 |
| scripts/predict.py | 读取已保存模型，重新生成同一公开数据池的测试预测 |
| tests/test_train.py | 折映射错误、类别输入、折外覆盖和预测复现的回归测试 |

先读src/train.py中的run_training，按下面的顺序理解：

1. **读取原始数据并构造特征。** 不从已全量填补的train_clean.csv开始交叉验证。
2. **按PassengerId关联folds.csv。** 行顺序改变也能正确关联；漏行、重复、额外乘客、同行组跨折会报错。
3. **训练折拟合填补器。** 验证折只transform。逻辑回归的StandardScaler也在本折Pipeline中拟合。
4. **训练与保存折外概率。** 每位乘客恰好由未训练过自己的那一折模型预测一次。
5. **统计结果。** 保存五折平均准确率、样本标准差、全部折外预测合并后的准确率与log loss。
6. **可选全量训练。** 方案确定后在全部训练数据上重新拟合，预测测试集，保存完整模型包。

人数计数继续使用公开train+test的无标签特征池；这是当前团队约定的批次可见设定。
它不使用测试标签，但确实使用测试特征分布。训练和预测必须保持同一池与代码版本。

## 两个模型的输入

- LogReg：当前59列one-hot矩阵，StandardScaler + LogisticRegression(C=1, max_iter=3000)。
- CatBoost：使用同一基础特征的原生类别表示，默认30列，即23列数值/布尔和7列类别。包含CabinZone，连续CabinNum不直接入模。
- CatBoost参数在第一次运行前固定：600轮、depth=6、learning_rate=0.05、l2_leaf_reg=5、seed=42、CPU两线程。
- 首版不使用外层验证折来选择迭代数，不根据全体折外结果搜索分类阈值；阈值固定为0.5。
- 原生类别输入是CatBoost支持的接口，类别列通过cat_features指定，参考[官方说明](https://catboost.ai/docs/en/features/categorical-features)。

这里两种编码的列数不同，比较的是相同基础信息下的模型方案，并非同一数值矩阵上的纯算法对照。
更换模型、参数、编码、特征或预处理策略时，使用新的实验名。

## 运行命令

在仓库根目录执行。已有虚拟环境无需重新创建。

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v

# 五折逻辑回归；默认实验名带运行时间
.\.venv\Scripts\python.exe -m scripts.train --model logreg

# 五折CatBoost，并额外训练全量模型、生成测试预测和提交文件
.\.venv\Scripts\python.exe -m scripts.train --model catboost --fit-full
```

已保存实验使用明确名称，重跑时请换新名称。程序拒绝覆盖已有目录。

```powershell
.\.venv\Scripts\python.exe -m scripts.train --model logreg --run-name logreg_baseline_20261018
.\.venv\Scripts\python.exe -m scripts.train --model catboost --run-name catboost_baseline_20261018 --fit-full
```

以上两个明确命名的实验已经执行时，不要原样重跑；省略--run-name即可自动生成新目录。

## 输出和团队交接

```text
reports/experiments/training/<实验名>/
├── fold_metrics.csv          每折训练/验证准确率、log loss、样本数和列数
├── oof_predictions.csv       按原始训练乘客顺序的折外预测，供成员4比较与融合
├── summary.json              配置、版本、数据/源码哈希、Git提交号、汇总指标
└── feature_importance.csv    CatBoost全量训练后的特征重要性，仅--fit-full时生成

outputs/<实验名>/             仅--fit-full时生成，本地忽略
├── test_predictions.csv      测试乘客编号、概率、布尔标签
└── submission.csv            仅PassengerId和Transported，符合提交模板

models/<实验名>/              本地忽略
└── bundle.joblib             模型、填补器、列顺序、配置和数据哈希
```

折外表固定列：PassengerId、GroupId、fold、Transported、probability、prediction。
Transported是真实标签，probability是预测为True的概率，prediction是probability>=0.5。
成员4应按PassengerId关联，检查真实标签和fold一致后，再比较或融合概率；不能依赖两个文件恰好同一行顺序。
reports中的折外记录可随代码共享；模型与测试预测仍在Git忽略目录。

sample_submission.csv的乘客编号、行数和顺序会在生成时校验，Transported以True/False写出。
生成本地提交文件不代表已上传Kaggle，也不代表团队已经选定最终模型。

## 复现保存模型的预测

```powershell
.\.venv\Scripts\python.exe -m scripts.predict --bundle models/catboost_baseline_20261018/bundle.joblib
```

默认写入outputs/对应实验名/reproduced/；再次复现时用--output-dir指定新的目录。
预测入口核对三个原始数据文件的哈希，避免换了数据池后悄悄改变姓氏人数等统计口径。
该入口用于复现当前比赛批次；替换任意新数据后应重新明确特征池并训练。
